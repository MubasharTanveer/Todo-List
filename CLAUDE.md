# Claude Code Integration Guide

## Project Commands
- Test: `npm test`
- Lint: `npm run lint`
- Build: `npm run build`
- Dev: `npm run dev`
- Run MCP Stdio Server: `node server/mcp-server.js`

## Code Guidelines
- Strict TypeScript types for all entities.
- Decoupled storage abstraction via `StorageAdapter<T>`.
- Responsive Vanilla CSS design system with CSS custom properties.
- Model Context Protocol (MCP) JSON-RPC compatibility.
